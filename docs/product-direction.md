## product-direction.mdについて

- このドキュメントはCitytoriの現在のプロダクトの方向性や判断材料を整理するためのもので、確定仕様ではありません
- 実装や画面を確認した結果、よりよい案がある場合は見直します

## 目指す体験

- Citytoriはしりとりをきっかけに街を歩き、その日の発見を楽しく気軽に記録できるサービスです
- しりとり自体を競うことよりもしりとりを理由に普段とは少し違う視点で街を見ることを大切にします
- 散歩中に見つけたことばや写真を残し、あとからその日の発見を振り返れる体験を目指します

## 基本的な利用の流れ

1. しりとり散歩を始める
2. 次に探す文字を確認する
3. 街の中からその文字で始まるものを探す
4. 写真とことばを記録する
5. 必要に応じて位置情報やメモも記録する
6. 次に探す文字を確認して散歩を続ける
7. 好きなタイミングで散歩を終える
8. 記録したことばや写真を振り返る

## MVPで大切にすること
- MVPでは以下の体験を優先します
  - しりとり散歩を始められる
  - 現在探す文字が分かる
  - 見つけたことばを記録できる
  - 写真を記録できる
  - しりとりのルールに沿って次の文字が決まる
  - 必要に応じて位置情報を記録できる
  - 必要に応じてメモを記録できる
  - 進行中の散歩を確認して続けられる
  - 過去の散歩を振り返れる
  - 写真やことばを時系列で振り返れる
  - 位置情報がある場合は地図でも振り返れる

## MVPでは不要なもの

- 以下は現在のMVPでは優先しません
  - 他のユーザーとの交流を目的としたSNS機能
  - 散歩記録の公開や共有を中心とした機能
  - 公開URLによる他ユーザーへの共有
  - 詳細な歩行ルートの記録
  - 散歩の開始地点や終了地点そのものを記録する機能
  - 散歩中の発見を記録して振り返る体験から離れる機能

## 機能を追加するときの判断基準

- 新しい機能やUIを検討するときは以下を判断材料にします
  - 散歩が楽しくなるか
  - 記録が気軽にできるか
  - 普段とは違う視点で街を見るきっかけになるか
  - あとから発見を振り返る楽しさにつながるか
  - また散歩したいと思えるか

- 機能を増やすこと自体を目的にせず、Citytoriが目指す体験に必要かどうかを優先して判断します

## 現在の用語候補
- 用語はまだ確定しておらず、画面で揺れている部分もあります
- 実際のコードや画面を確認しながら分かりやすく一貫した表現に見直します

| コード・概念 | 現在の表示候補 | 意味 |
| --- | --- | --- |
| WordChainWalk | しりとり散歩 | 1回の散歩全体 |
| active walk | しりとり散歩中 | 現在進行中の散歩 |
| finished walk | 完了したしりとり散歩 | 終了した散歩 |
| WordChainWalkStep | 記録 | 散歩中に追加した1件の記録 |
| word | ことば | 街で見つけて登録するもの |
| target_char | さがす文字 | 次に探す文字 |
| latest step | 直前の記録 | 最後に追加した記録 |
| add step | 記録を追加する | 新しいことばを登録する |
| timeline | タイムライン | 散歩の記録を時系列で振り返る表示 |
| map | 地図 | 位置情報から発見した場所を振り返る表示 |
| start | しりとり散歩を始める | 散歩を開始する |
| finish | しりとり散歩を終える | 散歩を終了する |
| completion | しりとり散歩完了 | 散歩終了後の状態・画面 |
| delete walk | しりとり散歩を削除 | 散歩全体を削除する |
| delete latest step | 直前の記録を削除 | 最後に追加した記録を削除する |

## 今後確認したいこと
- 実際の画面とコードで用語がどのように使われているか
- 同じ意味のものを複数の言葉で表現していないか
- ユーザーから見て分かりにくい用語がないか
- MVPから外した機能の表示や導線が残っていないか
- 現在の画面構成がCitytoriの目指す体験と合っているか
